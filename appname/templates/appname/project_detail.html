Statement of method

This award's footprint is reported on the GHG Protocol Corporate Standard category structure. It combines direct attribution of purchases charged to the award with an apportioned share of each participating site's shared running emissions, allocated on the basis of {{ project.get_allocation_basis_display|lower }}.

Conversion factors, grid intensities, procurement spend factors and their sources are set out in full on the methodology page, which is public and needs no login.

Limitations. Apportionment assumes the declared basis is a reasonable proxy for a site's shared resource use; it is not a metered measurement of the award's own consumption. {% if footprint.travel_logged %} Travel is attributed per journey from the award's travel log, using {{ travel_factor_source }}; it replaces the award's share of site flights and road travel, so journeys missing from the log are not counted. {% else %} No journeys are logged, so travel is apportioned from site figures rather than attributed per trip; an award with unusually heavy or light travel will be over- or under-stated on that line. {% endif %} Procurement uses spend-based factors, which assume price tracks carbon. {% if footprint.sites_missing_data %}
{{ footprint.sites_missing_data|length }} site(s) on this award have no emission data, so their contribution is currently counted as zero. {% endif %}
